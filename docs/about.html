About mathΣτοά

mathΣτοά is an archive of mathematical projects hosted in public Git repositories. It covers research, exposition, and formal proof projects, including work in progress.

What is an open mathematical research project?

An open mathematical research project is a public Git repository containing publicly accessible mathematical work. Such work can still be under development, and the repository serves the purpose of sharing raw results that are not yet ready for publication.

mathΣτοά is particularly intended for research carried out with AI, including for the digestion of articles written with AI. Making the material accessible as a project allows it to be studied, corrected, extended, and digested.

A project may also link to a publicly accessible website (for example a GitHub Pages site) that explains its aims and introduces the material in the repository. We encourage the website to contain some form of raw data (for example a PDF file with a version of the research work that is kept up to date).

Scope

A project may begin with a conjecture, a collection of examples, a reading programme, or an attempt to explain a difficult proof. mathΣτοά gives that work a public introduction: what it is about, where it stands, and where to read more.

The work stays in its own repository. The archive connects people to it. We welcome research, exposition, and formal proof projects, including projects that are incomplete.

How do we measure contribution?

Submission criteria

To be listed, a project should have:

  1. A public Git repository with a DOI for an archived release. GitHub explains how to get a DOI for a repository with Zenodo. A project website is optional.
  2. Substantive material that another person can engage with: notes, examples, partial results, explanations, or formal work.
  3. A named steward who maintains the project or is authorised to submit it.
  4. A clear description of progress and whether contributions are welcome.
  5. Reuse terms and a contribution policy that explain how work is accepted and credited.

Submissions receive a basic editorial check for scope, clarity, and completeness. Listing does not certify mathematical correctness, establish originality, or constitute peer review. State any review or formal verification precisely, with a link to the relevant version.

The DOI identifies an archived version of the work, so readers can cite the version a listing describes. The pilot announcement feed records accepted projects.
