About

mathΣτοά lists mathematical projects hosted in public Git repositories. A public Git repository is accessible to anyone, but only contributors authorised by the maintainers of the repository can make changes.

Scope

mathΣτοά is intended to index ongoing mathematical research projects that are not yet ready for publication in peer-reviewed journals or on preprint servers. It is particularly aimed at research carried out with large language models (LLMs). Repositories listed on this website can include for example raw LLM-generated material to be improved with further exploration, or to be digested with human effort, or the formal proof verification of a mathematical result.

Our goal is to reduce the pressure to publish results that have not yet been fully digested, or that may still be improved in future iterations. We do not prescribe any form of collaboration, and the names listed on this site are not expected to correspond to the authors of an eventual publication. It is up to the maintainers of each repository to decide how they want to manage contributions (e.g., through a classical collaboration with a fixed number of authors, a reading group, or a broader community effort).

We encourage the use of websites (such as GitHub Pages) to describe the aims of a project and give some information about the type of collaborative work that is being undertaken.

Submission criteria

To have your project listed, you should have:

  1. A public Git repository containing one or more mathematical results in some form, (e.g. LaTeX or Lean code). This includes LLM-generated results, formal proof verifications and incomplete articles.
  2. We require that the repository is readable and understandable by humans, and that it contains a clear description of its mathematical content. When possible, we ask for an introduction to the repository’s aims, with a brief description of the form of collaborative work that it hosts (e.g. a list of collaborators, or that it is a community effort) and a link to the mathematical results (e.g. a PDF). Preferably, the description should occur in a website (such as GitHub Pages), although README files may also be accepted, subject to moderation.
  3. Optionally, a DOI for referencing purposes.
    How to get a DOI for a GitHub repository with Zenodo.
  4. The content of the repository should be reasonably new to the list, and we will moderate to ensure that there are no significant overlaps.

Submissions are reviewed before publication.

Moderation and responsibility

We may decline to list a project at our discretion, without giving a reason, except where an explanation is required by law or our complaints procedure.

Listing on this website does not certify mathematical correctness, establish originality, or constitute peer review. We do not take any responsibility for the content of listed repositories, and we do not provide any guarantee that the content is accurate, complete, or lawful.

Repository maintainers are responsible for the content of their repositories. Questions about that content should be directed to them.

Reports, complaints and feedback

To report a listing, suspected illegal content, a credit or copyright problem, a privacy or accessibility concern, or to appeal a moderation decision, email contact@math-stoa.org.
