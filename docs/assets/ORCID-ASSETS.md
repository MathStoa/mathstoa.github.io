# ORCID identifier icons

`orcid-unauthenticated.svg` is the unmodified default unauthenticated iD icon
from the official ORCID Brand Library, downloaded 4 November 2026 after
the operator approved the library’s download terms. It is used only with
ORCID record links, with the required “(unauthenticated)” suffix. It is an
ORCID brand asset, not relicensed as MathStoa code under MIT.

Source: https://orcid.filecamp.com/s/o/LdPTOOrMoSrjElD5/hvHwbPudFy9YB7Hs/SYYuVmbGk7Y4qec2

SHA-256: `4666eec4ed5b890976f309c54de2e2694ab97d07b3af180e7889b49d5e0219ad`

Use and display: https://info.orcid.org/documentation/integration-guide/orcid-id-display-guidelines/

The existing `orcid.svg` is used only for identifiers collected through the
authenticated record-holder workflow. Authentication confirms control of
the iD, not authorship, the contributor’s name or mathematical correctness.
